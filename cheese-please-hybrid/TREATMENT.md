# Cheese, Please! (hybrid edition) — 30 s, 2D characters in a realistic 3D room

Reference look: the 2021 live-action/2D hybrid cat-and-mouse feature (flat-colour cel characters with soft shading and very expressive faces, placed in a photographic world). This is only a look reference: the characters are original (Pip, a white mouse; Boris, a ginger tabby), same story, timing, voices and cues as the other editions.

Pipeline: the room is rendered as a realistic 3D scene (PBR walnut floor, plaster wall, studio HDRI, soft shadows, real tea-set props) with a level camera, so the character plane maps exactly onto the screen. The characters are drawn as 2D cel animation (flat fills, one soft shadow band, cream muzzle/belly, glossy eyes with highlights, tongue and teeth) on the same frame, each with a soft contact shadow so they sit in the room. Poses are filtered over +-0.1 s so motion is smooth.
